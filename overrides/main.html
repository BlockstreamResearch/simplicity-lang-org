Or let your coding agent set it up (Claude Code, Codex, Cursor…)

Your agent follows the setup instructions:

  1. Checks the platform, Rust 1.91+, git, curl and Node.js. It uses WSL on Windows and installs Rust with rustup if it's missing.
    cargo --version
  2. Installs simplexup, the Simplex installer (source).
    curl -L https://smplx.simplicity-lang.org | bash
  3. Installs Simplex 0.2.0.
    simplexup --install 0.2.0
  4. Adds the SimplicityHL skill to your agent.
    npx skills add brenorb/freedom-skills -s simplicityhl-simplex
  5. Creates a first project, writes a test for its contract with the skill, and runs it.
    simplex init hello_simplicity && cd hello_simplicity && simplex build && simplex test
