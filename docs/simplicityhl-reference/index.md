# Introduction

[SimplicityHL](../glossary.md#simplicityhl) is a high-level language for writing Bitcoin [smart contracts](../glossary.md#smart-contract).
In other words, SimplicityHL is a language for expressing spending conditions of [UTXOs](../glossary.md#utxo) on the Bitcoin blockchain.

SimplicityHL looks and feels like [Rust](https://www.rust-lang.org/).
Developers write SimplicityHL, Bitcoin full [nodes](../glossary.md#node) run [Simplicity](../glossary.md#simplicity).
